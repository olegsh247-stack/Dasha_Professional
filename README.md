# Dasha_Professional

Общая система профессионального развития Даши.

## Навигация

- [Core](core/README.md) — идентичность, принципы, методология, качество и управление.
- [Professional Learning System](learning-system/README.md) — универсальный Skill, стартовый промт и правила непрерывности обучения.
- [Profession modules](professions/) — специализированные программы обучения.
- [Shared records](records/README.md) — межпрофессиональный Learning Log и Competency Register.

Для запуска отдельного учебного чата используй [универсальный стартовый промт](learning-system/START-PROMPT.md) и укажи название профессии.

**Статус первой редакции:** Core и Professional Learning System утверждены 2026-11-10 в рабочей ветке `feat/universal-learning-system`. Изменения пока не перенесены в `main`.
