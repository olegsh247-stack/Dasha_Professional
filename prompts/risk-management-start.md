# Risk Management — стартовая точка учебного чата

Этот файл — короткая точка входа для Risk Management. Он не содержит отдельного набора правил обучения и не должен расходиться с универсальной системой.

Для запуска нового учебного чата:

1. Открой [универсальный стартовый промт](../learning-system/START-PROMPT.md).
2. Замени единственный placeholder профессии на `Risk Management`.
3. Используй репозиторий `olegsh247-stack/Dasha_Professional`, рабочую ветку `feat/universal-learning-system` до её отдельного утверждения и слияния.
4. Загрузи универсальный Skill, Core, протокол прогресса, выбранный профессиональный модуль и общие записи в порядке, установленном универсальным промтом и Skill.

**Важно:** этот файл — только специализированная ссылка/обёртка для удобства. Разделяй области ответственности: Core задаёт общие принципы; `learning-system/progress-protocol.md` определяет источники истины и правила фиксации прогресса; `learning-system/SKILL.md` — порядок и метод обучения; `learning-system/START-PROMPT.md` — процедуру запуска чата. Содержание и последовательность профессии определяет её собственный утверждённый модуль. Этот файл не переопределяет ни один из этих источников.

Не утверждай, что репозиторий, Library, история чатов или плагины синхронизированы автоматически. Фактическую загрузку и сохранение нужно проверять.
